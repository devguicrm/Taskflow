# TaskFlow — Lista de Tarefas Avançada

Projeto de uma aplicação web responsiva para gerenciamento de tarefas, desenvolvida com **HTML, CSS e JavaScript**.

## 🔗 Acesse o projeto

[Ver projeto publicado](COLOQUE_AQUI_O_LINK_DO_GITHUB_PAGES)

## 📌 Sobre

O **TaskFlow** permite cadastrar, editar, concluir, excluir e filtrar tarefas em uma interface moderna. O projeto utiliza `LocalStorage` para manter os dados salvos no navegador mesmo após fechar a página.

## 🚀 Funcionalidades

- Cadastro de tarefas;
- Edição de tarefas;
- Exclusão de tarefas;
- Marcar como concluída;
- Filtro por status;
- Filtro por prioridade;
- Filtro por categoria;
- Busca por título, descrição, categoria ou etiqueta;
- Cards de estatísticas;
- Barra de progresso;
- Tema claro e escuro;
- Dados salvos com LocalStorage;
- Layout responsivo.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Font Awesome
- Google Fonts
